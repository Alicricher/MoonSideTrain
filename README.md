# CLI Task Manager

Инструкция по публикации, обязательным PR и веткам: [CONTRIBUTING.md](CONTRIBUTING.md).

Простой учебный менеджер задач на Python без внешних библиотек.

## Запуск

Из папки проекта:

```bash
python3 main.py
```

На Windows можно использовать `python main.py`.

Программа умеет добавлять, показывать и завершать задачи. После изменения
задачи автоматически сохраняются в `tasks.json` рядом с кодом.
Новая задача получает статус `TODO`, завершённая — `DONE`.

## Файлы

- `main.py` — меню и ввод пользователя.
- `task_manager.py` — операции с задачами.
- `storage.py` — чтение и запись JSON.
- `tasks.json` — список задач, изначально пустой.

## Фичи для друзей (ещё не реализованы)

- Удаление: `delete_task(task_id)`, ветка `feature/delete-task`.
- Приоритеты LOW / MEDIUM / HIGH, ветка `feature/task-priority`.
- Поиск: `search_tasks(query)`, ветка `feature/search-tasks`.

В функциях можно первым аргументом передавать `tasks`, как в базовом коде.
Каждый добавляет свою функцию и пункт меню в отдельной ветке,
отправляет Pull Request и просит другого участника проверить код.
Перед новой веткой нужно обновить локальную `main` через `git pull`.
Учебные задачи из личного запуска не нужно включать в PR:
перед коммитом проверьте изменения в `tasks.json`.
